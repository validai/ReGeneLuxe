Privacy Policy

Last updated 11 October 2026

What this policy covers

This policy describes the ReGeneLuxe workspace. These legal pages themselves do not require an account, do not set cookies, and do not run analytics or advertising.

Why information is used

Information is used to sign the operator in, connect a platform the operator chooses, show connection status, keep workspace records, and carry out an approved provider action. ReGeneLuxe does not sell personal information.

Signing in

The operator signs in with Google. That sign-in requests the basic identity needed to open the workspace: the account identifier, name, and email address. A session is kept so the operator stays signed in. Gmail and YouTube permissions are separate and are requested only when those connections are started.

Connected accounts

When a platform is connected, ReGeneLuxe can store the provider account identifier, username or display name, profile address and image when the provider returns them, the granted scope, token expiry, connection status, and timestamps. Provider access tokens and refresh tokens are stored in an encrypted credential vault. They are not placed in the browser as page content.

Connecting an account sends the authorization request to that provider. The provider decides what it returns. ReGeneLuxe then keeps the result for that workspace.

Workspace records

The workspace can store campaigns, content metadata, schedules, account configuration, and publication records when a publish is attempted. Local media files stay with the workspace. If a publish needs a public address for a provider to fetch media, a temporary copy may be placed with a configured media host and removed after the provider’s fetch window.

Google and Gmail

A Gmail connection, when the operator turns it on, uses a read-only Gmail grant. ReGeneLuxe stores message metadata: sender, recipients, subject, dates, labels, message and thread identifiers, whether attachments exist, and a short snippet of up to 240 characters. It does not store the full message body. Those message records are kept out of workspace backups. Campaign features receive whether Gmail is connected and how fresh the last sync is, not the message contents. Disconnecting Gmail removes the stored Gmail credential.

TikTok

The current TikTok connection requests only user.info.basic. When TikTok returns them, ReGeneLuxe may store the open id, union id, display name, and avatar address, plus the access token, refresh token, scope, and expiry. This connection does not request posting or analytics access, and it does not upload videos.

Other providers

Instagram, Facebook, and YouTube connections store the identity those providers return, such as a professional account, Page, or channel, together with the credential in the vault. The same pattern applies to a later provider: ReGeneLuxe stores the identity and credential that provider’s authorization returns, and only the scopes that connection requested. A provider’s own policy also applies once you authorize it.

Retention and deletion

Connection and workspace records are kept while the workspace uses them. Disconnecting an account removes the stored provider credential for that connection. The account row can remain so the workspace history stays intact. There is no separate public deletion portal. A request to delete workspace records can be made through the contact below once a contact address is published.

Security

Provider credentials are encrypted before they are stored. Workspace access is limited to the signed-in operator. No compliance certification is claimed.

Your control

The operator chooses which accounts to connect, confirms a destination before it is saved, and can disconnect an account. Provider permissions can also be revoked in the provider’s own settings.

Children

ReGeneLuxe is an operator workspace. It is not directed to children under 13, and it should not be used to connect a child’s account.

Changes

This policy can be updated when the product’s data practices change. The date above shows the current version.
